## 角色剧场：修复"重复/无节奏/莫名停/开不了场"（第九轮）
- 用户反馈：对话场景很奇怪——经常重复内容、没有节奏且与轮次无关、莫名其妙结束、也可能完全没开始。
- 根因与修复：
  1. **重复/无推进**：系统提示缺"推进+别重复"约束，且未发送 `frequency/presence_penalty`。改法：提示词加第6条"每句向前推进、绝不复读"，并在请求体用 `extra_body:{frequency_penalty:0.5,presence_penalty:0.4}`（后端 `streamOpenAICompatibleWithClient` 会把 ExtraBody 透传给 Ollama/MiniMax，无需改后端）；temperature 0.9→0.85，CONTEXT_WINDOW 30→24（更紧的窗口逼模型向前）。
  2. **无节奏/与轮次无关**：新增 `stageHint(round,total)` 叙事弧线（开场→交锋→激化→收口），写进系统提示的"【对话进度】这是第 X / Y 轮"段，并随轮次切换阶段指令；进度条新增阶段徽标 `pg-stage`。
  3. **莫名其妙结束**：`resumeShow` 没复位 `pauseRequested/skipFlag`，从暂停恢复时立刻又被旧标志打断而静默停在 paused → 统一为 `beginShow()`（开演/继续共用，进循环前复位 stopAll/pauseRequested/skipFlag/interruptedMsg）；`runLoop` 加 try/catch，异常显式写入 interruptedMsg 而非吞掉。
  4. **完全没开始**：`loadModels` 失败静默 catch 导致 model 为空、按钮禁用且无提示 → 增加 `modelsError` ref + 顶部重试横幅（带"重试"按钮）；auto-select 首个可用模型。
  5. **恢复 off-by-one**：旧 `runLoop` 用 `completedRounds + (nextRoleIdx===0?1:0)` 在暂停后续跑会把上一轮角色错标成当前轮 → 改为 `startRound=completedRounds+1`，本轮内从 `nextRoleIdx` 续跑、新轮从 0 开始；`finally` 按 `completedRounds>=total` 判定 idle(结束) vs paused。
- **关键发现**：本机 Ollama 当前默认模型 `nex-n2.5-mini-unc:gguf` 是**推理模型**，先吐 `reasoning` token 再吐 content；MAX_REPLY_TOKENS 太小（曾降到400）会把预算全给推理、content 被截断/置空 → 表现为"没内容/莫名结束"。已恢复为 700，并实测 2角色×3轮对话质量良好（有来有回、逐轮收敛到带条件的决策、零复读）。
- 部署：本机 pnpm build（系统 node、unset NODE_OPTIONS）→ HOT_DEPLOY 叠加；容器健康，ocr/asr/redis 不受影响。访问 /role-play，密码 123654789。
